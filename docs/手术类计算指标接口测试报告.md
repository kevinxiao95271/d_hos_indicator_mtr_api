## 修复建议

### 1. 除零处理（优先级：高）

**后端计算服务修改示例**:
```java
public Double calculateIndicator(String expression, Map<String, Double> itemValues) {
    try {
        String[] parts = expression.split("/");
        if (parts.length == 2) {
            Double numerator = itemValues.get(parts[0].trim());
            Double denominator = itemValues.get(parts[1].trim());

            // 增加除零检查
            if (denominator == null || denominator == 0) {
                return null; // 或返回特定标识，如 -1
            }

            return numerator / denominator;
        }
    } catch (Exception e) {
        logger.error("计算指标失败: " + expression, e);
        return null;
    }
    return null;
}
```
