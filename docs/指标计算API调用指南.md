# 指标计算API调用指南

## API地址
```
POST http://localhost:8080/dgear/api/indicator-result/calculate
```

## 请求参数

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| metricCode | String | 是 | 指标编码（指标名称） | 手术患者并发症发生率 |
| timeDimension | String | 是 | 时间维度 | YEAR（年）、QUARTER（季度）、MONTH（月）、DAY（日） |
| startDate | String | 是 | 开始日期 | 2023-01-01 |
| endDate | String | 是 | 结束日期 | 2023-12-31 |

## 调用示例

### 1. 使用curl命令（推荐）

#### Windows PowerShell
```powershell
# 使用URL编码的中文指标名称
$metricCode = [System.Web.HttpUtility]::UrlEncode("手术患者并发症发生率")
curl "http://localhost:8080/dgear/api/indicator-result/calculate?metricCode=$metricCode&timeDimension=YEAR&startDate=2023-01-01&endDate=2023-12-31" -Method POST

# 或者直接使用编码后的值
curl "http://localhost:8080/dgear/api/indicator-result/calculate?metricCode=%E6%89%8B%E6%9C%AF%E6%82%A3%E8%80%85%E5%B9%B6%E5%8F%91%E7%97%87%E5%8F%91%E7%94%9F%E7%8E%87&timeDimension=YEAR&startDate=2023-01-01&endDate=2023-12-31" -Method POST
```

#### Linux/Mac Bash
```bash
curl -X POST "http://localhost:8080/dgear/api/indicator-result/calculate?metricCode=%E6%89%8B%E6%9C%AF%E6%82%A3%E8%80%85%E5%B9%B6%E5%8F%91%E7%97%87%E5%8F%91%E7%94%9F%E7%8E%87&timeDimension=YEAR&startDate=2023-01-01&endDate=2023-12-31"
```

### 2. 使用Postman/Apifox

- **请求方式**: POST
- **URL**: `http://localhost:8080/dgear/api/indicator-result/calculate`
- **参数类型**: Query Params
- **参数列表**:
  - metricCode: 手术患者并发症发生率
  - timeDimension: YEAR
  - startDate: 2023-01-01
  - endDate: 2023-12-31

### 3. 使用JavaScript/Axios
```javascript

})
```

## 注意事项

1. **指标编码已更新**
   - ❌ 旧的数字编码（如"8.1"、"10.3.2"）已废弃
   - ✅ 请使用完整的指标名称作为metricCode

2. **中文编码问题**
   - 在URL中使用中文时，需要进行URL编码
   - 或者使用Postman等工具会自动处理编码

3. **数据可用性**
   - 部分指标可能因2023年数据不存在而返回空值或除零错误
   - 这是正常现象，不影响API功能

4. **表达式正确性**
   - ✅ 所有表达式已修正为正确格式（不含*100）
   - 例如：病死率表达式为 `a0040/a0032` 而非 `a0040/a0032*100`
