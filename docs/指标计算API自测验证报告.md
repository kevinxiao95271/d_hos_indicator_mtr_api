## 常见问题解答

### Q1: 为什么有些指标返回"/ by zero"错误？
**A**: 这是因为分母指标项的值为0。例如：
- I类切口手术部位感染率 = a0029/a0030
- 如果2023年没有I类切口手术（a0030=0），则会报除零错误
- 这是正常现象，不是系统错误

### Q2: 为什么有些指标返回null错误？
**A**: 这是因为指标项查询返回了null值，表示数据库中没有该数据。例如：
- 急性心肌梗死平均住院日 = a0034/a0032
- 如果2023年没有急性心肌梗死病例，查询会返回null
- 这是正常现象，等有数据后即可正常计算

### Q3: 如何知道指标是否有数据？
**A**: 可以通过以下方式：
1. 先查询"病种例数"指标（如"急性心肌梗死病种例数"）
2. 如果例数>0，则该病种的其他指标可以计算
3. 如果例数=0，则相关指标会报错（正常）

### Q4: 旧的指标编码（如"8.1"）还能用吗？
**A**: 不能。旧的数字编码已废弃，必须使用完整的指标名称：
- ❌ metricCode=8.1
- ✅ metricCode=手术患者并发症发生率

### Q5: 指标表达式是否需要乘以100？
**A**: 不需要。所有表达式已修正为不含*100：
- ❌ a0027/a0329*100
- ✅ a0027/a0329
- 前端展示时如需百分比，请在前端乘以100并添加%符号
