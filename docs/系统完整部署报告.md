## API使用指南

### 2023年度指标计算示例

#### 调用格式
```bash
POST http://localhost:8080/dgear/api/indicator-result/calculate
```

#### 参数
- `metricCode`: 指标名称（需URL编码）
- `timeDimension`: YEAR
- `startDate`: 2023-01-01
- `endDate`: 2023-12-31

#### PowerShell示例
```powershell
# 计算手术患者并发症发生率
$metricCode = [System.Web.HttpUtility]::UrlEncode("手术患者并发症发生率")
curl "http://localhost:8080/dgear/api/indicator-result/calculate?metricCode=$metricCode&timeDimension=YEAR&startDate=2023-01-01&endDate=2023-12-31" -Method POST
```

## 重要说明

### 1. 指标编码变更
- ❌ 旧格式: 使用数字编码（如 8.1, 10.3.2）
- ✅ 新格式: 使用指标名称（如 手术患者并发症发生率）
- ⚠️ 注意: 旧的数字编码已废弃，请使用新格式

### 2. 表达式格式
- ✅ 所有病死率/感染率表达式不含*100
- ✅ 例如: `a0027/a0329` 而非 `a0027/a0329*100`
- 💡 如需百分比展示，请在前端处理

### 3. B15字段日期比较
- ✅ 所有查询已修复为使用 `DATE(B15)`
- ✅ 确保日期比较准确性
- 📝 详见: [B15字段日期比较修复报告.md](B15字段日期比较修复报告.md)

### 4. 数据可用性
- ⚠️ 部分指标因2023年数据不足可能返回错误
- 常见错误:
  - `/ by zero` - 分母为0（无相关病例）
  - `null` - 指标项查询返回空值
- 💡 这是正常现象，不影响系统功能
