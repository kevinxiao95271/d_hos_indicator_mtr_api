## ⚠ 发现的SQL配置问题

### 问题描述

虽然接口查询成功并返回了0，但指标项的SQL配置存在错误：

**当前配置（错误）**:
```sql
SELECT COUNT(*) AS result_value
FROM d_mr
WHERE STR_TO_DATE(B15, '%Y/%m/%d') BETWEEN #{startDate} AND #{endDate}
  AND (C03C LIKE '81.51%' OR C03C LIKE '81.52%'
    OR C06x01C LIKE '81.51%' OR C06x01C LIKE '81.52%')
```

**问题**:
- 使用**诊断字段** (C03C, C06x01C) 查询**手术编码** (81.51, 81.52)
- C03C/C06x01C 是诊断编码字段（存储ICD-10疾病编码，如I50.904）
- 81.51/81.52 是手术编码（ICD-9-CM-3手术分类）

**应该使用手术字段**:
```sql
SELECT COUNT(*) AS result_value
FROM d_mr
WHERE STR_TO_DATE(B15, '%Y/%m/%d') BETWEEN #{startDate} AND #{endDate}
  AND (C14x01C LIKE '81.51%' OR C14x01C LIKE '81.52%')
```
