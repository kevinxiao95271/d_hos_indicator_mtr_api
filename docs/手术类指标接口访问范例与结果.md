## 重要说明

### 1. 返回值为0的情况

当 `value` 为 `0` 时，表示以下情况：

- **分母为0**: 该时间段内无相关病例（正常业务场景）
- **计算结果为0**: 例如病死率，分子为0时

建议前端处理：
- 直接显示 "0"
- 或显示 "-" 表示无数据
- 提示文字："该时间段内无相关病例"

### 2. 计算逻辑

所有计算类指标都遵循以下逻辑：

```javascript
if (denominator === 0) {
  return 0; // 除零情况返回0
}
return numerator / denominator;
```

### 3. 错误处理建议

**推荐实现**:
```java
public Double calculateIndicator(String expression, Map<String, Double> itemValues) {
    String[] parts = expression.split("/");
    Double numerator = itemValues.get(parts[0].trim());
    Double denominator = itemValues.get(parts[1].trim());

    // 除零时返回0
    if (denominator == null || denominator == 0) {
        return 0.0;
    }

    return numerator / denominator;
}
```
