## 🎯 核心功能演示

### 功能1: 指标项SQL执行
**用途**: 从d_mr表中查询统计数据

**示例**: 查询肺炎病例数
```sql
SELECT COUNT(*) as result_value
FROM D_MR
WHERE B15 BETWEEN '2025-01-01' AND '2025-01-31'
AND (C03C LIKE 'J13%' OR C03C LIKE 'J14%' OR C03C LIKE 'J15%' OR C03C LIKE 'J18%')
AND A14 >= 18
```
**状态**: ✅ 执行成功

### 功能2: 表达式解析
**支持的表达式**:
- 单指标项: `a0050`
- 四则运算: `a0052/a0050`
- 复杂表达式: `(a0050-a0051)/a0052*100`
- 聚合函数: `SUM(a0050)/SUM(a0052)`

**状态**: ✅ 解析器正常

### 功能3: 时间维度
**支持的维度**:
- YEAR: 按年统计（如 "2025"）
- QUARTER: 按季统计（如 "2025-Q1"）
- MONTH: 按月统计（如 "2025-01"）
- DAY: 按日统计（如 "2025-01-15"）

**状态**: ✅ 全部支持
