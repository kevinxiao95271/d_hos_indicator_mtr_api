## 问题发现与修复

### 发现的问题

1. **B15日期格式问题**
   - ❌ 原SQL: `DATE(B15) BETWEEN`
   - ✅ 修复: `STR_TO_DATE(B15, '%Y/%m/%d') BETWEEN`
   - **原因**: B15格式为 `2020/1/18 10:00` (斜杠分隔)，需要用STR_TO_DATE转换

2. **ICD编码匹配问题**
   - ❌ 原SQL: `C03C = 'I50'` (精确匹配)
   - ✅ 修复: `C03C LIKE 'I50%'` (模糊匹配)
   - **原因**: 实际编码为 `I50.904`，精确匹配无法匹配到

### 修复执行

#### 修复1: B15日期格式
```sql
UPDATE t_indicator_item
SET query_sql = REPLACE(query_sql, 'DATE(B15) BETWEEN', "STR_TO_DATE(B15, '%Y/%m/%d') BETWEEN")
WHERE query_sql LIKE '%DATE(B15) BETWEEN%';
```

#### 修复2: ICD编码匹配
```sql
UPDATE t_indicator_item
SET query_sql = REPLACE(
    REPLACE(query_sql, "C03C = 'I50'", "C03C LIKE 'I50%'"),
    "C06x01C = 'I50'", "C06x01C LIKE 'I50%'"
)
WHERE item_code IN ('a0041', 'a0043', 'a0046', 'a0049');
```
