# 手术类指标项SQL修复报告

## 修复时间
2025-12-31

## 问题描述

发现所有手术类指标项的SQL配置错误：使用**诊断字段**（C03C, C06x01C等）查询**手术编码**。

### 问题示例

**错误配置**:
```sql
SELECT COUNT(*) AS result_value
FROM d_mr
WHERE STR_TO_DATE(B15, '%Y/%m/%d') BETWEEN #{startDate} AND #{endDate}
  AND (C03C LIKE '81.51%' OR C06x01C LIKE '81.51%')  -- ❌ 错误：诊断字段
```

**正确配置**:
```sql
SELECT COUNT(*) AS result_value
FROM d_mr
WHERE STR_TO_DATE(B15, '%Y/%m/%d') BETWEEN #{startDate} AND #{endDate}
  AND C14x01C LIKE '81.51%'  -- ✓ 正确：手术字段
```

### 字段说明

| 字段类型 | 字段名 | 用途 | 编码示例 |
|---------|--------|------|---------|
| 诊断字段 | C03C | 主要诊断编码 (ICD-10) | I50.904, J18.9 |
| 诊断字段 | C06x01C | 其他诊断编码1 (ICD-10) | I50.904, J18.9 |
| **手术字段** | **C14x01C** | **手术编码 (ICD-9-CM-3)** | **81.51, 74.0, 36.1** |

4. ... (所有C06x系列) → `C14x01C`
