**现象**: 当数据为0时（如2月和3月），除法计算失败
**状态**: FAILED
**错误**: "表达式计算失败：null"

**建议**:
在ExpressionParser中增加除零保护：
```java
if (denominator == 0) {
    return null; // 或返回特殊标记
```
